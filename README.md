# 🎮 NoKakulaLeveling

Браузерное расширение для Twitch: **скрывает Какула Левелинг и спам ботов из чата** и добавляет **быстрые команды с автодополнением** прямо в поле ввода.

## ✨ Возможности

### 🚫 Фильтрация чата
- **Скрытие спама прокачки и ботов:** скрывает сообщения бота Алекстры, Nightbot и команды других зрителей.
- **Отдельные переключатели для ботов:** в настройках канала можно точечно включить или выключить фильтрацию для конкретного бота (например, скрыть прокачку, но оставить Nightbot).
- **Ваш ник под защитой:**
  - Ваши собственные сообщения никогда не скрываются.
  - Сообщения с упоминанием вашего ника (`@ник`) всегда остаются видны в чате.
- **Поддержка смайликов и символов:** скрывает даже те сообщения бота, которые начинаются с кастомных смайлов Twitch или эмодзи (💸, ‼️, 𖡎 и др.).
- **Мгновенное переключение на лету:** при клике по тумблеру расширение сразу скрывает или возвращает сообщения прямо в открытом чате без перезагрузки страницы.
- **Универсальность:** работает одинаково чётко как на **прямых трансляциях (Live)**, так и на **записях стримов (VOD)**.

### ⚡ Быстрые команды
- **Всплывающие подсказки:** начните писать с `!` прямо в чате — появится меню с 5 лучшими совпадениями.
- **Разделение по категориям:** команды сгруппированы по разделам («База», «Какула Левелинг», «Vclash»), каждую категорию можно включить или выключить отдельно.
- **Метка аргументов:** если команде нужен параметр (например, `!работа` или `!клип`), расширение покажет оранжевую плашку **«требуется аргумент»**.
- **Удобное управление:** выбор подсказки кликом мыши или клавишей **Tab**, навигация стрелками **↑ / ↓**, закрытие на **Esc**. Клавиша **Enter** не перехватывается и отправляет сообщение как обычно.

### 🌙 Тёмная тема Twitch
- Кнопка переключения темы (🌙 / ☀️) в правом верхнем углу попапа. Запоминает ваш выбор и умеет автоматически подстраиваться под системную тему.

### 🔄 Удобные обновления
- **Обновление паттернов в 1 клик:** кнопка **«Обновить паттерны с GitHub»** скачивает свежие команды и фильтры прямо из репозитория — переустанавливать всё расширение больше не нужно!
- **Проверка версии:** кнопка «Проверить обновление» сравнивает версию с GitHub Releases и подскажет, если выйдет новая версия.

### 🔒 Приватность
Расширение работает полностью локально в вашем браузере. Оно не собирает, не хранит и не передаёт никакие личные данные на сторонние серверы.

## 📥 Установка для Chromium-браузеров (Chrome, Яндекс, Edge, Opera):

### Способ 1: Из магазина расширений Chrome 
(Ждём проверку модерации)

### Способ 2: Из релиза
1. Перейди в раздел **[Releases](https://github.com/SubaKon/NoKakulaLeveling/releases)** и скачай последний ZIP-архив.
2. **Распакуй** архив в любую папку на компьютере.
3. Открой браузер (Chrome, Яндекс, Edge, Opera) и введи в адресной строке: `chrome://extensions`
4. В правом верхнем углу **включи переключатель «Режим разработчика»**.
5. Нажми кнопку **«Загрузить распакованное расширение»** (слева вверху).
6. Выбери папку, куда ты распаковал архив.
7. Готово! Нажми на иконку расширения (пазл 🧩 вверху справа браузера) и настрой расширение.

### Способ 3: Из исходного кода (больше фич, больше багов)
1. Нажми зелёную кнопку **Code** → **Download ZIP**.
2. Распакуй архив.
3. Открой `chrome://extensions` и включи **«Режим разработчика»**.
4. Нажми кнопку **«Загрузить распакованное расширение»** и выбери папку с расширением.
5. Готово! Молись, что баги будут незначительные 🙂

## 🚀 Использование

1. Кликни по иконке расширения в панели браузера.
2. **Введи свой Twitch ник** в верхнем поле и нажми **«Сохранить»** — без ника тумблеры каналов защищены от включения, чтобы случайно не скрыть адресованные тебе сообщения.
3. Включи тумблер канала (например, **AlexstraWho**):
   - Откроются списки **«Фильтры сообщений:»** (боты) и **«Быстрые команды»** (категории).
   - Оставь включенными нужные пункты или настрой под себя.
4. Печатай в поле ввода чата `!` — появятся подсказки. Выбирай мышью или жми **Tab**.
5. Наслаждайся чистым чатом! ✨

## 📂 Как обновить?

### Только паттерны и команды (теперь прямо в расширении!)
1. Открой попап расширения.
2. Нажми кнопку **«Обновить паттерны с GitHub»**.
3. Расширение само скачает свежие списки команд и фильтров.
4. Перезагрузи страницу Twitch, если она была открыта.

### Само расширение целиком  (Если не скачивали из магазинов расширений)
1. Скачать новый релиз из раздела Releases.
2. Открыть папку расширения и распаковать архив с заменой.
3. Перейти в `chrome://extensions` и нажать кнопку обновления 🔄 на карточке расширения.
4. Перезагрузить страницу Twitch.
